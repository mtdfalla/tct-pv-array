PERFORMANCE:

Evaluation time: ~0.5-1 sec (4×3, 300 points)

Stability: 10-1000 W/m², 25-75°C


COORDINATE SYSTEM:
------------------
G_map shape: (R, C) where R=rows, C=columns
Row = parallel block (modules at same voltage)
Rows in series (same current through all)

    Col0   Col1   Col2
   [M00] [M01] [M02]  Row 0
   [M10] [M11] [M12]  Row 1
   [M20] [M21] [M22]  Row 2
   [M30] [M31] [M32]  Row 3


ERROR HANDLING:
---------------
- Very low G (<1 W/m²): Module treated as off
- Negative I: Not supported (no reverse bias modeling)
- Non-convergence: Returns last iterate
- NaN/Inf: Clamped exponentials prevent this


NOTES:
------
* Module temperature uniform within substrings
* Bypass diodes: 3 per module (18 cells each)
* Bypass activation: V_sub < -0.5V
* Newton-Raphson with safeguards
* Bisection for Isc finding
* Automatic MPP detection
